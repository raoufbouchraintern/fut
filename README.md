# Yakeey Advisor Cards — Three.js + Anime.js

XI départ conseillers en 3D (Three.js) avec animations d’intro (Anime.js).

## Lancer

```bash
npm install
npm run dev
```

Ouvre **http://127.0.0.1:5173/**

## Stack

- **Vite** — bundler / dev server
- **Three.js** — terrain 3D + cartes en formation 4-3-3
- **Anime.js** — intro camera/cartes + panneau détail

## Logique métier

- 6 stats : PUB% · CLU% · TRF · SAT · TXN · CA
- OVR = Offre 35% + Demande 15% + Transactions 50%
- Thèmes : 75–84 Gold · 85–89 Neon · 90–94 Emerald · 95–99 Icon
